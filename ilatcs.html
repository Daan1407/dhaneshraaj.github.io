CASE STUDY / FINAL YEAR PROJECT

How I approached ILATCS

DHANESH RAAJ THANAMURTHI

ILATCS — Intelligent Log Analysis and Threat Correlation System — was my final year project. The project brought together my interests in cybersecurity, Linux systems, log analysis and SOC-style investigation.

The problem

Security logs can contain useful evidence, but raw events are difficult to investigate when they are isolated. My project focused on making those events easier to analyse by bringing related activity into a single workflow.

The approach

The system was designed around collecting and analysing Linux security events, identifying suspicious activity, correlating related events and presenting the results in a way that supports investigation.

LOG EVENT → NORMALISE → CORRELATE → THREAT CONTEXT → INVESTIGATE

What I learned

The project strengthened my understanding of security monitoring, log analysis, threat correlation and the practical thinking required when building a security-focused system. It also gave me a stronger appreciation for how a SOC analyst moves from an individual event toward a broader incident picture.
