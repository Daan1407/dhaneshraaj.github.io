# Dhanesh Raaj — Recruiter Portfolio v2

This is a static personal website designed as a long-term recruiter portfolio and technical blog.

## Run
Open `index.html` in a browser.

## Publish
Recommended permanent route: GitHub Pages.
1. Create a public repository named `YOUR-GITHUB-USERNAME.github.io`.
2. Upload everything in this folder.
3. GitHub → repository Settings → Pages.
4. Select the branch containing these files and save.
5. Your site will be available at `https://YOUR-GITHUB-USERNAME.github.io/`.
6. Later, add a custom domain if desired.

## Blog
Real starter articles are included under `/blog`.
Add future posts as HTML files and link them from `index.html`.

## Important
Replace the placeholder LinkedIn/contact information if any details change.
